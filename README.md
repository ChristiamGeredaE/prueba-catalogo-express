# [Resolución de Prueba Técnica ]

## 📝 Descripción
La prueba consiste, en la construcción de dos microservicios uno para catalogo-servicie y el otro para inventary-service , donde se deben comunicar por medio de una APIs Rest , donde cada uno tiene una base de datos independiente, se levantó un contenedor para  sql-server.

---

## 🛠️ Versiones Usadas
 versiones de las tecnologías y herramientas 
* **Java:** Versión 17
* **Spring Boot:** Versión 4.1.1
* **Base de Datos:** SQL Server 
* **Gestor de Dependencias:** Maven
* **Control de Versiones:** Git
* **Docker

---

## 📋 Requisitos Previos
Antes de ejecutar el proyecto en tu entorno local, asegúrate de contar con lo siguiente instalado:
* Java 17 en adelante,  instalado y configurado en las variables de entorno.
* Gestor de bases de datos ( SQL Server).
* Herramienta para probar APIs (Postman, Swagger).
* Maven (o puedes usar el wrapper incluido en el proyecto).
